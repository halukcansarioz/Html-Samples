## About the Project
This project was created to practically demonstrate the use of HTML tags — the foundation of web development — how to structure the skeleton of a page, and how to apply semantic web standards.

- **Developer:** Haluk Can SARIÖZ
- **Languages:** HTML (99.8%), CSS (0.2%)
- **Purpose:** Learn and practice HTML fundamentals through hands-on examples

---

## Sample Contents
The exercises in this repository generally cover the following topics:

- **Basic Tags:** Headings, paragraphs, and text formatting
- **Links & Media:** Usage of `<a>`, `<img>`, `<video>`, and `<audio>`
- **Lists:** Ordered and unordered lists
- **Tables:** Rows, columns, headers, and cell merging structures
- **Forms:** Collecting user input, input types, buttons, and validations
- **Semantic HTML5:** Meaningful structures such as `<header>`, `<nav>`, `<section>`, `<article>`, `<aside>`, and `<footer>`
- **Block & Inline Elements:** Understanding the difference between block-level and inline tags
- **Iframes:** Embedding external content within a page
- **Head Elements:** Meta tags, title, and other elements inside the `<head>` section

## Project Structure
The repository is organized into 12 topic-based folders, each containing focused HTML examples:

```text
Html-Samples/
├── 01-Html h etiketi/                              # Heading tags (h1–h6)
├── 02-Html p etiketi tricler/                      # Paragraph tags & tricks
├── 03-Html formatlama etiketleri/                  # Text formatting tags
├── 04-Html alıntı yapma/                           # Quoting and citation
├── 05-Html renk verme/                             # Applying colors
├── 06-Html image oluşturma/                        # Creating and embedding images
├── 07-Html tablo oluşturma/                        # Building tables

├── 11-Html head etiketleri arasında neler kulanırız/ # Head section elements

```

## Development Workflow
When adding a new HTML example or updating existing code, you can follow these steps:

### 1. Fork
First, fork the repository to your own GitHub account.

### 2. Create a New Branch
Creating a new branch for each exercise or fix keeps things organized:
```bash
git checkout -b feature/new-html-example
```

### 3. Push Your Code
After making and committing your changes, push the branch to GitHub:
```bash
git push origin feature/new-html-example
```

## Installation & Usage

**1. Clone the repository:**
```bash
git clone https://github.com/halukcansarioz/Html-Samples.git
```

**2. Navigate to the project directory:**
```bash
cd Html-Samples
```

**3. Open any example in your browser:**
Simply double-click any `.html` file inside the topic folders, or use a code editor (VS Code, etc.) with a live server extension.
